# Recommended ISOs

1. Ubuntu 26.04 LTS Desktop — https://ubuntu.com/download/desktop
2. Ubuntu 26.04 LTS Server — https://ubuntu.com/download/server
3. Windows 11 official ISO — only if you will install Windows
4. Optional: Xubuntu 26.04 — https://xubuntu.org/download/

Optional tools: GParted Live, Clonezilla.

Copy the `.iso` files onto the `INSTALL` partition.
